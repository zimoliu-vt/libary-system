REST API · JSON

Build with your
library data.

A small, predictable API for browsing and managing your book collection on the local network. The machine-readable API description is available at /api.json.

Base URL
01

Pagination and filters

Collection endpoints accept limit, offset, and category query parameters. Activity logs also accept action=ADD|UPDATE|REMOVE and q=search.

limit1–200 records
offsetStarting position
categoryExact category name
GET/books

List books

Returns the complete collection or a paginated and filtered window. Supported filters are q, category, and status; sort values are added, title, author, year, and category.

Request
GET /books?limit=200&offset=0&q=asimov&status=Finished&sort=author
GET/categories

List categories

Returns the allowed Jev categories, current book counts, and whether a server-side API key is configured.

GET/stats

Library statistics

Returns totals grouped by category and reading status, the top five authors, and the publication-year range.

POST/books/add

Add a book

Creates a new book and records the action in the activity log. Send JSON for a book without a cover, or use multipart form data with an optional cover image. JPEG, PNG, WebP, and GIF files up to 6 MB are accepted. A duplicate title-and-author pair returns HTTP 409.

JSON · without a cover
{
  "title": "The Left Hand of Darkness",
  "author": "Ursula K. Le Guin",
  "year": 1969,
  "url": "https://example.com/books/left-hand-of-darkness",
  "auto_categorize": true,
  "reading_status": "Want to Read",
  "personal_rating": 5
}
Multipart · with a cover
curl -X POST /books/add \
  -F "title=Dune" \
  -F "author=Frank Herbert" \
  -F "year=1965" \
  -F "url=https://example.com/books/dune" \
  -F "cover=@/path/to/dune.jpg"
titleText · required
authorText · required
yearInteger · required
urlHTTP(S) URL · optional
coverImage · optional · max 6 MB
POST/books/update

Edit a book

Updates an existing book. JSON can edit metadata or remove a cover. Use multipart form data to upload a replacement cover.

JSON body
{
  "id": 42,
  "title": "Dune",
  "author": "Frank Herbert",
  "year": 1965,
  "url": "https://example.com/books/dune",
  "remove_cover": false,
  "category": "Science Fiction",
  "reading_status": "Reading",
  "personal_rating": 4
}
POST/books/bulk-update

Bulk update books

Changes the category, reading status, or both for several numeric book IDs.

JSON body
{
  "ids": [12, 18, 24],
  "category": "Science Fiction",
  "reading_status": "Finished"
}
POST/books/categorize

Categorize with TypeSafe Jev

Classifies one existing book from its title, author, and year. The TypeSafe API key stays on the Flask server in .env. A successful response includes the chosen category, confidence when supplied by Jev, and model name.

JSON body
{ "id": 42 }
POST/books/libby-availability

Check NLB Libby

Searches NLB’s public OverDrive catalogue by title, verifies the author, and stores matching eBook or audiobook copies, holds, availability, and a search link. Availability is a snapshot and should be refreshed before borrowing.

One book
POST /books/libby-availability
{ "id": 42 }
Reload-safe background check
POST /books/libby-availability/bulk
{ "refresh_all": false }

GET /books/libby-availability/bulk
GET/books/export

Import and export

Download with GET /books/export?format=json or format=csv. Import by posting a multipart JSON or CSV file under the file field to /books/import. Duplicate title-and-author pairs are skipped.

POST/books/find

Find books

Performs a case-insensitive partial match across title, author, year, category, reading status, and book ID. Optional category and status fields narrow the result.

JSON body
{ "query": "Ursula", "status": "Finished" }
POST/books/remove

Remove a book

Deletes the book matching the supplied numeric identifier.

JSON body
{ "id": 42 }
GET/logs

Activity logs

Returns additions and removals. Paginated results are ordered newest first and can be filtered by action or text.

Request
GET /logs?limit=200&offset=0&action=ADD&q=dune
